# Markdown Reader

Um leitor de arquivos **README.md** com visual GitHub-style.

## Funcionalidades

- 📂 Upload de arquivo `.md`
- 📝 Colar Markdown diretamente
- 🔗 Carregar de URL raw do GitHub
- 💻 Split view: código vs preview
- 🌙 Tema dark/light

  console.log("Olá, mundo!");
